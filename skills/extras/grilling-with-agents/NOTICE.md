# Source attribution

Grilling with Agents is a locally maintained method based on Tobi's explicit design decisions.
Selected techniques are adapted from Matt Pocock's skills, reviewed at revision
`4ae2317ddb22b046e26455e4f9c9b3aaaf62212d` on 2026-11-04.

- https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/productivity/grilling/SKILL.md

The local method preserves existing project ownership and conditional dependencies.
It does not adopt the upstream host tool names, fixed vocabulary, artifact layout
or automatic authority. The included MIT notice applies to the adapted upstream
material; it does not assign a license to the repository's other authored material.
See [LICENSE-Matt-Pocock.txt](LICENSE-Matt-Pocock.txt).

The user-defined lead-agent interviewee, report-only result without user questions
for every invocation, worked examples and reasoned handoff to existing plans are
local additions. This single interaction rule replaces the earlier local split
between a five-question allowance and a technical zero-question mode.
Domain Modeling, Codebase Design / Design It Twice, Wayfinder and To Tickets at
the same upstream revision also informed the composition; they are not mandatory
runtime dependencies. Ordinary Grilling remains the separate human-interview method.
