# Delegation examples

- A small local fix with one known file and test stays with the main agent. Delegating it adds briefing and review without useful parallel work.
- Two independent user capabilities with settled API contracts may run in parallel. Each owner changes its capability and tests. The main agent checks both changes and the combined integration.
- If two agents need the same migration or API decision, settle that prerequisite first. Different filenames do not make their work independent.
- A large diagnostic log can go to one read-only analyst with the log path, error question, permitted filters, and a request for exact failure locations. A local deterministic filter is preferable when it answers the question directly.
- An independent reviewer receives the requirements, relevant diff, and acceptance criteria. Do not prime the reviewer with the implementer's conclusion.
- A blocked agent returns the exact missing contract or permission and preserves its partial artifact. The main agent decides whether to supply data, change the assignment, or stop.
