# Method lineage

Repository-owned method, revised on 2026-11-05. The previous Technical Writing
package lived under `skills/engineering/technical-writing/` and primarily taught
repository documentation, following the earlier Synopsis method. Its full old
tree is archived in this repository before replacement (`e94a45b` source revision).

That repository method now belongs to Engineering Documentation. This package
keeps the Technical Writing name for manuals, procedures and reference material
whose source and lifecycle do not depend on owning a software repository. Its
workflow and calibration example are newly authored; the shared pencil icons
and explicit invocation policy are preserved.

[Diátaxis](https://diataxis.fr/application/) informs the distinction between
learning, doing, understanding and lookup. [W3C WAI's complex-image guidance](https://www.w3.org/WAI/tutorials/images/complex/)
informs concise textual equivalents for explanatory diagrams. Both were reviewed
on 2026-11-05; neither requires a fixed chapter tree or a graphic on every page.
The drawing and prose methods remain with Editorial SVG Diagrams and Unslop.
